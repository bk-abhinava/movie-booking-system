# 🎬 Movie Booking System

A production-style full-stack movie ticket booking system.

## Features

- User authentication
- Movie browsing
- Cinema and show management
- Interactive seat selection
- Temporary seat reservation
- Online payments
- Booking confirmation
- Email notifications
- Booking history
- Cancellation and refunds
- Waitlist
- Admin dashboard
- Concurrency control
- Load testing

## Tech Stack

### Frontend
- React

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Cache
- Redis

### Queue
- BullMQ

### Email
- Nodemailer

### Payment
- Razorpay / Stripe

### Testing
- Jest
- Supertest
- k6
